# Lopaca
Lopaca is a llama-server GUI frontend written in python using standard libraries, currently deisgned for Linux with GTK but others will come later. Features include RAG document support and rudimentary agentic support.

# Usage
Start an instance of llama-server with your favorite LLM. Mostly tested with Qwen3.6 and 3.8 27b.
Make sure gtk python libraries are installed. Otherwise it's all standard libraries.
```
./run.sh
```
